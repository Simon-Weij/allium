
# Allium

[![codecov](https://codecov.io/gh/Simon-Weij/allium/branch/main/graph/badge.svg)](https://codecov.io/gh/Simon-Weij/allium)
[![License: MPL 2.0](https://img.shields.io/badge/License-MPL%202.0-brightgreen.svg)](LICENSE)

OpenSubsonic-compatiable music streaming service that fetches its own music

## What is this?
Allium aims to be an OpenSubsonic-compatiable music streaming service similar to [navidrome](https://github.com/navidrome/navidrome/tree/master). But it can fetch its own music, giving you an experience similar to Spotify, yet self-hostable
